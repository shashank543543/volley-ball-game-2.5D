# 2.5D Volleyball Game

A browser‑based 2.5D volleyball game built with **Three.js** (rendering) and **cannon‑es** (physics). The project includes a Vite development setup, basic scene, physics, and a game loop ready for further gameplay features.

## Quick Start (local)
```powershell
cd "C:/Users/shashank s/Downloads/volley ball website"
npm install            # install dependencies
npm run dev            # start Vite dev server (http://localhost:5173)
npm run build          # create production bundle in ./dist
```

   ```
3. Enable **GitHub Pages** (Settings → Pages) and point it to the `gh‑pages` branch or the `main` branch **/ (root)** if you prefer to serve the `dist/` folder directly.

     git push -u origin gh-pages
     ```
   - GitHub will provide a URL like `https://<USERNAME>.github.io/volleyball-game/`.
